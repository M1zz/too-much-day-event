## 🚀 배포

GitHub Pages로 바로 호스팅할 수 있습니다.

1. 이 레포를 GitHub에 push
2. **Settings → Pages → Source**에서 `main` 브랜치 / `/ (root)` 선택
3. 자동으로 `https://<username>.github.io/too-much-day-event/` 에 배포됩니다
